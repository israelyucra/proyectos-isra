# Agenda de Contactos

## Descripción
Programa en **C++** que permite administrar una agenda de contactos:  
- Agregar  
- Modificar  
- Borrar  
- Listar  

## Instalación
1.clone el repositorio
2.se compila con en visualstudio code
   - Abra programa y Presionar Ctrl+Shift+B para compilar la tarea.
3. ejecute el programa
 - una ves compilado abra un terminal
   y ejecute el programa ./AgendaDeContactos.exe
